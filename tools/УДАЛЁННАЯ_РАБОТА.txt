Полный рабочий стол домашнего ПК + ЭТОТ чат Cursor
==================================================

ВАЖНО
-----
• История чатов Cursor хранится ТОЛЬКО на том ПК, где открыт Cursor.
• Чтобы продолжить ЭТОТ чат — подключайтесь к РАБОЧЕМУ СТОЛУ домашнего ПК
  и открывайте Cursor там же (не Remote-SSH на ноутбуке).

• Порт 3389 (RDP) в интернет НЕ открыт — только через SSH-туннель на VPS.

Перед выходом из дома
---------------------
• ПК включён, вы вошли в Windows (Win+L — можно, «Выход» — нельзя).
• Туннель ssh → VPS запущен (автозапуск при входе в Windows).

На ноутбуке (один раз)
----------------------
1) Ключ:
   scp root@aptown11.fvds.ru:/root/home-pc-ssh/id_ed25519_home %USERPROFILE%\.ssh\id_ed25519_home

2) Скопируйте tools\connect_home_desktop.bat на ноутбук (или из GitHub).

Каждый раз — полный рабочий стол
--------------------------------
1) Запустите connect_home_desktop.bat
   (или вручную: ssh -L 13389:127.0.0.1:3389 -i ключ root@aptown11.fvds.ru -N
    затем mstsc /v:127.0.0.1:13389)

2) Логин: учётная запись Windows домашнего ПК (Жека) + пароль Windows.

3) На удалённом рабочем столе откройте Cursor — все чаты на месте,
   включая текущий.

4) Проект: E:\Виртуальный сервер\Проект 1

Админка Django на ноутбуке через RDP
------------------------------------
Браузер на удалённом рабочем столе: http://127.0.0.1:8000/admin/
(запустите runserver в терминале Cursor на домашнем ПК)

Если RDP не подключается
------------------------
На домашнем ПК локально:
  powershell -File tools\start_home_ssh_tunnel.ps1
  (или перезагрузка и вход в Windows)

На VPS должно быть:
  ss -lntp | grep 3389   → 127.0.0.1:3389
