Как создавать штрихкоды
  1. Во вкладке «Штрихкоды» выберите тип штрихкода (EAN-13, EAN-8, Code 128 или Другой).
  2. В поле «Штрихкод» введите код вручную или поднесите сканер — он введёт код как с клавиатуры.
  3. При необходимости укажите комментарий (например: «основной», «упаковка 6 шт»).
  4. Нажмите «Сохранить» внизу страницы.

Один товар может иметь несколько штрихкодов. Один и тот же код не может быть назначен разным товарам. По штрихкоду можно искать товар в списке и быстро добавлять позиции сканером.
