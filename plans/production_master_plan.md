# План развития раздела "Производство"

Дата создания: 21.06.2026  
Владелец плана: команда ERP  
Статус плана: в работе

## Цель

Собрать единый, предсказуемый и проверяемый производственный контур:  
продажи -> план производства -> снабжение -> выполнение этапов -> склад -> себестоимость/учет.

## Как отслеживаем прогресс

- Статусы задач: `todo` -> `in_progress` -> `done` -> `blocked`.
- После каждого завершенного шага обновляем:
  - статус в этом файле,
  - краткий факт-результат в "Журнале прогресса".
- Если задача заблокирована, фиксируем причину и следующий шаг.
