Проект 1 — Laser ERP
====================

СПОСОБ 1 (проще всего)
----------------------
Дважды щёлкните по файлу:  run.bat
Откройте в браузере:       http://127.0.0.1:8000/admin/


СПОСОБ 2 (из PowerShell)
-------------------------
cd "E:\Виртуальный сервер\Проект 1"
.\.venv\Scripts\python.exe manage.py runserver


СПОСОБ 3 (Cursor / VS Code)
----------------------------
1. Откройте папку «Проект 1» как проект (File → Open Folder).
2. Выберите интерпретатор: .venv\Scripts\python.exe
3. F5 или Run → «Django: runserver (Проект 1)»


Если «не запускается»
---------------------
1. Создать окружение (один раз):
   python -m venv .venv
   .\.venv\Scripts\pip install -r requirements.txt

2. Смотреть красный текст в окне — там причина ошибки.

3. Ошибка в браузере «Connection refused» / код -102
   — сервер не запущен. Запустите run.bat или:
   .\.venv\Scripts\python.exe manage.py runserver 8000

4. Ошибка 500 на форме «Этап производства» (текст про таблицу
   core_productionstagecounterpartyservice) — в базе нет таблицы после миграции.
   Один раз выполните из папки проекта:
   .\.venv\Scripts\python.exe manage.py ensure_counterparty_table
   (или: fix_counterparty_table.py — вызывает ту же команду)
   Затем обновите страницу.

5. Левая панель «список приложений» в админке показывается только на главной
   странице http://127.0.0.1:8000/admin/ — на разделах Товары, Склад,
   Производство и т.д. навигация через верхнюю синюю полосу.
