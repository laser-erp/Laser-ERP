Правила Cursor для Laser ERP
=============================

Эта папка выложена на GitHub, чтобы локальные и облачные агенты
работали по одним и тем же инструкциям.

Файлы *.mdc подхватываются Cursor автоматически (alwaysApply / globs).

Ключевое для общения с владельцем проекта:
  plain-russian-for-user.mdc — без жаргона (commit/push/deploy и т.п.).
